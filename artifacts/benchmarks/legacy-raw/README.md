# Raw benchmark artifacts

These files retain historical outputs from individual experiments, with
contributor home prefixes replaced by `${HOME}`. The [shared provenance manifests](../../provenance/README.md)
record original Git-blob hashes and current hashes; numerical results and all
other canonical bytes are preserved.
They include negative runs and runs later found to contain implementation or
configuration defects. They are evidence for the dated write-ups, not a
current performance baseline.

For current summaries and configuration guidance, use
[benchmark references](../../../docs/reference/benchmarks.md) and
[configuration guidance](../../../docs/guides/turboquant-recommendations.md).
